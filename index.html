    No gamepad detected.

    Standard mapping: right face button = A, bottom face button = B, Back = Select, Start = Start. A second pad drives player 2.

    Under the hood

    • CPU 6502 core, every bus access is one cycle; all 256 opcodes
    • PPU dot-by-dot renderer with the real fetch pipeline
    • APU 5 channels, non-linear mixer, AudioWorklet output
    • Saves battery RAM and 4 save-state slots in local storage

    Mappers

      The game library only contains original games from this project and homebrew games whose licenses allow redistribution (see roms/). Only load other ROM files you are legally allowed to use, such as dumps of cartridges you own. Everything runs locally in your browser; nothing is uploaded.
